# Flowery (Glue) 1.3.0

Статус: кандидат для проверки. Публикация пока не выполнена.

## Что нового по сравнению с 1.2.0

В 1.2.0 уже появились автоматический выбор техник, быстрые повторные попытки, сетевые профили и трей. В 1.3.0 доработаны адаптация к сети, передача данных и поведение настроек.

### Чем больше пользуетесь, тем больше опыта у Flowery

Flowery накапливает результаты работы техник обхода и использует их при следующих подключениях. Регулярное использование в одной сети помогает находить подходящие варианты и реже повторять неудачные попытки. Оценки стратегий сохраняются между запусками; краткосрочные наблюдения о маршрутах имеют ограниченный срок действия.

На новой сети или при изменении блокировок подбор может занять время. По последней пользовательской проверке изображения Discord начали загружаться через 1–2 минуты использования. Это результат конкретной сессии, а не обязательное время ожидания: улучшение не гарантировано, и отдельные соединения могут по-прежнему обрываться. Не сбрасывайте оценки без необходимости; при смене сети Flowery учитывает её отдельный контекст.

### Обход и загрузка страниц

- Исправлены повреждение HTTP-тела и сборка ClientHello из нескольких TLS-записей.
- Передача TLS использует ограниченные неблокирующие буферы. Зависание небольшого ответа учитывается при выборе следующего подключения.
- Убраны необоснованные запреты публичных IP, скрытая блокировка домена и принудительное закрепление стратегий и узла Discord. DNS-адреса и наблюдения о передаче участвуют в выборе маршрута.
- Успех TLS-рукопожатия отделён от наблюдаемой передачи данных. После зависания учитывается конкретный маршрут; сбой одного сайта не объявляет общий IP нерабочим для всех сайтов.
- Исправлен цикл перебора CDN: короткий штраф больше не возвращает поиск к первым адресам раньше проверки остальных кандидатов. Ручной выбор техники сохраняется при повторных попытках.

### Настройки и удобство

- Пользовательские настройки сохраняются при смене профиля; собственный DNS и отключение IPv6 применяются в рабочих путях.
- Исправлено восстановление ряда настроек Windows, добавлены таймауты системных команд. Запуск не завершает чужой процесс на занятом порту.
- HTTP по умолчанию пересылается без искусственного перенаправления. Явные сопоставления `hosts.txt` работают только после включения настройки.
- Комплект использует конфигурацию рядом с EXE и не требует установленного Python.
- Исправлена проверка TLS-сертификатов защищённого DNS. Восстановление DNS и MTU сохраняет данные для повторной попытки при ошибке команды Windows.
- Подготовлены чистые комплекты для Windows и с исходниками: без чужих оценок стратегий, привязок сетей и журналов; с контрольными суммами и сведениями о сборке.

## Проверено

Автономные тесты запускаются в изолированной копии проекта без изменения пользовательских данных. На локальном EXE проверены справка, чтение внешнего конфига и запуск/остановка отдельного прокси без изменения системных прокси, DNS и TTL. Для ряда крупных ресурсов сверены длины и SHA-256 между HTTP/1.1 и HTTP/2.

## Известные ограничения

- Стабильная доступность всех сайтов не подтверждена. В сетевых проверках наблюдались таймауты Discord, X, RuTracker и отдельных CDN-ресурсов; одна попытка на неподходящем маршруте может занять около 15 секунд, а первоначальный поиск — несколько минут. Последняя пользовательская проверка подтверждает восстановление Discord через 1–2 минуты, но не отсутствие сбоев в других сетях.
- Canva и часть других страниц могут загружаться неполностью. Ответ HTTP 403 может быть отказом самого сервиса, антибот-проверкой или региональным ограничением. Flowery не меняет внешний IP.
- Прокси не расшифровывает HTTPS и не определяет полноту каждого HTTP/2-потока; уже установленный TLS-сеанс нельзя перенести на другой IP без нового соединения клиента.
- Обычная пользовательская сессия готового EXE с правами администратора, применением и восстановлением настроек Windows, треем и голосовым звонком Discord требует дополнительной проверки.
- Исправления шлюза приёма логов имеются локально. Состояние развёрнутого шлюза и отзыв ранее использовавшегося токена необходимо подтвердить перед публикацией.

Перед обновлением сохраните прежнюю папку. Для отката завершите новую копию штатно, затем запустите прежнюю. Не переносите вслепую накопленные оценки между разными сетями.
