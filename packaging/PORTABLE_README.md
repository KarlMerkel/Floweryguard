# Flowery (Glue) 1.3.0 — Windows x64

Локальный кандидат на выпуск. Python для запуска этого комплекта не нужен.

1. Распакуйте ZIP в отдельную доступную для записи папку.
2. Завершите предыдущий Flowery через пункт `0` или `Ctrl+C`.
3. Запустите `start.bat`, подтвердите запрос прав администратора и выберите запуск службы в меню.
4. Для завершения используйте пункт `0` или `Ctrl+C`: приложение восстанавливает применённые настройки.

Для проверки доступности сайтов запустите `test.bat`. Статус `TLS OK` с кодом HTTP 403/404/520 не означает, что сервис доступен полностью. Наличие отдельных успешных запросов не гарантирует загрузку всей страницы.

Локальный HTTP/HTTPS CONNECT-прокси: `127.0.0.1:8118`. Flowery работает с приложениями, которые используют системный прокси или явно настроены на этот адрес. Это не VPN: внешний IP не меняется. UDP-голос Discord обслуживается отдельным WinDivert-помощником; TCP-прокси не заменяет его.

Настройки находятся в `config.ini`; профили — в `network_profiles.json`. Комплект содержит чистые шаблоны. При обновлении сохраните старую папку и сначала проверьте новую отдельно. Старые оценки стратегий автоматически переносить не требуется. Пользовательский `hosts.txt` действует только при `[targets] use_hosts_file = true`.

При использовании Flowery накапливает опыт работы техник обхода: чем больше наблюдений в вашей сети, тем обоснованнее последующий выбор. Первоначальный поиск маршрута может занимать несколько минут; по последней пользовательской проверке Discord восстановился через 1–2 минуты. Это не гарантия доступности каждого сайта. Сохранённые оценки не нужно регулярно очищать.

Журналы находятся в папке `Flowery/logs` внутри системных «Документов», в том числе при переносе «Документов» в OneDrive. При сбое запишите адрес сайта и время и сохраните журнал. Отправка отчёта из меню требует отдельного подтверждения.

В этот двоичный комплект не включён старый аварийный `stop.bat`, сбрасывающий DNS всех адаптеров. Для штатного завершения достаточно меню программы. Не запускайте одновременно старую и новую копии.

Известные ограничения и результаты проверок перечислены в `RELEASE_NOTES.md`. Контрольные суммы всех файлов — в `SHA256SUMS.txt`, сведения о сборке — в `BUILD_INFO.json`, состав архива — в `manifest.json`. Лицензия Flowery находится в `LICENSE`, сведения о внешних компонентах — в `THIRD_PARTY.md` и `licenses/`.
