# Flowery (Glue) 1.3.0

Локальная копия комплекта Flowery для Windows 10/11. Версия 1.3.0 находится в разработке; наличие этой папки не означает публикацию релиза.

Запустите `start.bat`, разрешите повышение прав и выберите профиль в меню. Пункт `1` включает или останавливает службу, `0` завершает работу с очисткой настроек.

В этом комплекте исходники находятся в `Floweryguard/`; пакет `flowguard/` обеспечивает совместимость импортов. Если исходники присутствуют, BAT запускает их через Python 3.8+. При отсутствии исходников используется `Flowery.exe`. Пакеты pip не требуются.

Прокси HTTP/HTTPS CONNECT слушает `127.0.0.1:8118`. Голосовой UDP Discord обслуживает помощник `winws.exe`/WinDivert из `zapret_bin`. Для системных настроек и драйвера нужны права администратора. Flowery не меняет внешний IP и не гарантирует обход ограничений во всех сетях.

`stop.bat` выполняет принудительную остановку и сброс параметров, в том числе DNS к DHCP. Для обычного завершения используйте меню.

Настройки находятся в `config.ini`, профили — в `network_profiles.json`, домены — в `whitelist.txt`. Логи сохраняются в `Flowery\logs` внутри системной папки «Документы», включая перенесённую в OneDrive.

В меню: `12` — DoH, `13` — калибровка, `14` — диагностика, `15` — тест сайтов, `16` — лог, `17` — обновление доменов, `18` — отправка отчёта после подтверждения.

Основной код разрабатывается в `flowguard/` корня репозитория. Подробное описание: [репозиторий Flowery](https://github.com/KarlMerkel/Floweryguard). Краткий порядок работы есть в `ИНСТРУКЦИЯ.txt`.

Архивы и EXE в локальной папке могут относиться к прежним сборкам. Хэши опубликованного комплекта следует сверять с соответствующим выпуском в [Releases](https://github.com/KarlMerkel/Floweryguard/releases).
