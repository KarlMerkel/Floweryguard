## ⚡ Чем Flowery принципиально отличается от аналогов?

Большинство инструментов на рынке (GoodbyeDPI, стандартные сборки zapret) используют **статические правила**: пользователю предлагается вручную перебирать десятки `.bat`-файлов (`preset_russia1.cmd`, `general_fake.bat` и т.д.), пока один из них случайно не заработает. Если провайдер меняет параметры фильтрации или на одном ресурсе работает один метод, а на другом — другой, соединение ломается.

Flowery решает эту проблему на принципиально ином инженерном уровне:

### 1. 🧠 Адаптивное обучение (Thompson Sampling Multi-Armed Bandit)
- Для каждого домена и целевой подсети `/24` Flowery поддерживает байесовские вероятностные распределения эффективности техник обхода:
  - **TCP Split** (разбиение первого пакета TLS ClientHello по границам SNI);
  - **TLS Record Fragmentation** (нарезка ClientHello на независимые валидные TLS-записи внутри одного TCP-сегмента);
  - **OOB Data (TCP Urgent)** (внедрение out-of-band байта прямо в позицию SNI для ослепления ТСПУ);
  - **BoringSSL Split** (адаптированная фрагментация для серверов Google/YouTube);
  - **Multi-Split & Combo Desync** (каскадные комбинации).
- Программа **непрерывно учится на реальных ответах серверов**: при сбоях алгоритм оперативно снижает вес неработающей техники и бесшовно переходит на победившую стратегию.

### 2. 🛡 Автодетект ТСПУ-сбросов и мгновенный Fast-Fallback
- Flowery в реальном времени анализирует поведение соединения:
  - Мгновенно распознаёт **ТСПУ RST-инжекцию** (поддельный сброс от фильтратора);
  - Отслеживает **Silent Drop** (зависание пакетов ТСПУ >500–600 мс);
  - Обнаруживает операторское подавление скорости (throttling тестовых сервисов).
- При фиксации блокировки соединение не рвётся с ошибкой для пользователя: активируется **Fast-Fallback**, сокет мгновенно перезапускается с альтернативной техникой, и страница открывается с первой попытки.

### 3. 🌐 Автоматические профили сетей (Network Fingerprinting)
- Flowery автоматически определяет текущую сеть (мобильный хотспот, домашний оптоволоконный Wi-Fi, корпоративная сеть) по сетевому отпечатку.
- Настройки адаптируются под условия конкретного подключения без необходимости ручного редактирования конфигов при перемещении с ноутбуком.

### 4. 🤝 Идеальный тандем с Flowseal zapret
- Flowery работает на уровне локального прокси-сервера (`127.0.0.1:8118`) и **НЕ использует WinDivert на TCP-уровне**.
- Никаких конфликтов сетевых драйверов, "синих экранов" (BSOD) или двойной десинхронизации пакетов. Flowery может работать как на 100% автономно, так и совместно с запущенным `winws.exe` (отдавая zapret прямой трафик там, где он уже настроен).

### 5. 📱 Полноценная маскировка тетеринга (Tethering Mask)
- **Фиксация DefaultTTL = 65** в реестре Windows (`Tcpip\Parameters`): при прохождении пакета через мобильный телефон TTL уменьшается на 1, и базовые станции оператора фиксируют стандартный смартфонный TTL=64. Платная раздача не активируется.
- **Включение RFC 1323 TCP Timestamps**: маскирует специфичные сигнатуры стека Windows.
- **Блокировка QUIC (UDP 443)** в Windows Firewall: принуждает браузеры и YouTube к стабильному TCP/TLS обходу.

## 🚀 Быстрый старт

### Вариант 1: Готовый бинарный релиз (рекомендуется)
1. Скачайте официальный архив из раздела [Releases](https://github.com/KarlMerkel/Floweryguard/releases):
   - **`Flowery_v1.2.0_Windows.zip`**
2. Распакуйте архив в удобную папку.
3. Запустите **`start.bat`** (или `Flowery.exe`) от имени Администратора.
4. Комплекс автоматически применит маскировку тетеринга, активирует системный прокси и начнёт адаптивный обход.

```cmd
git clone https://github.com/KarlMerkel/Floweryguard.git
cd Floweryguard
start.bat
```
*Внешние библиотеки не требуются — проект написан строго на стандартной библиотеке Python!*

## ❓ Часто задаваемые вопросы (FAQ)

<details>
<summary><b>1. Безопасен ли Flowery.exe? Почему антивирусы иногда реагируют на утилиты обхода блокировок?</b></summary>
Flowery имеет 100% открытый исходный код и собирается официальным компилятором PyInstaller. В отличие от спам-клонов, в Flowery нет скрытых DLL, рекламы или вредоносных модулей. Некоторые эвристические сканеры могут выдавать ложные срабатывания (Generic ML / False Positive) на любые утилиты, модифицирующие TTL в реестре или проксирующие локальный трафик. Сверяйте контрольную сумму SHA-256 с официальной таблицей выше или запускайте напрямую из исходных файлов через <code>python Floweryguard/main.py</code>.
</details>

<details>
<summary><b>2. Что делать при случайном закрытии окна консоли крестиком?</b></summary>
Flowery регистрирует системный обработчик <code>SetConsoleCtrlHandler</code>, автоматически восстанавливающий системные настройки Windows при закрытии. Если окно было принудительно убито через диспетчер задач, просто запустите <b><code>stop.bat</code></b> или выберите пункт <b>5</b> в меню для мгновенной нормализации всех параметров.
</details>

<details>
<summary><b>3. Как Flowery работает с голосовыми каналами Discord?</b></summary>
Для голосовых каналов Discord (WebRTC) используется модуль <code>voice_helper</code>, направляющий голосовые UDP-потоки без конфликтов с TCP. Если ваш мобильный провайдер блокирует UDP целиком, Discord автоматически переключается на WebRTC over TCP (порт 443), который фрагментируется и маскируется через Flowery.
</details>
