==============================================================================
            FLOWERY (GLUE) — ИНСТРУКЦИЯ ПО ЗАПУСКУ И ИСПОЛЬЗОВАНИЮ
==============================================================================

Flowery (Glue) — автономный инструмент для обхода ограничений мобильных операторов
при раздаче интернета (тетеринг) и DPI-блокировок в тандеме с Flowseal zapret.

Не требует установки сторонних библиотек (100% чистый Python 3.8+).

------------------------------------------------------------------------------
 1. БЫСТРЫЙ СТАРТ
------------------------------------------------------------------------------
1. Запустите файл "start.bat" (правой кнопкой мыши -> Запуск от имени администратора).
   * При запуске скрипт автоматически запросит права Администратора, если они нужны.
2. В консоли отобразится цветной логотип и результаты авто-диагностики сети.
3. Flowery автоматически:
   - Зафиксирует TTL = 65 (скрывает факт раздачи со смартфона от мобильного оператора).
   - Включит локальный прокси 127.0.0.1:8118 с техниками TCP Split и TLS Fragmentation.
   - Настроит системный прокси Windows (все браузеры Chrome, Edge, Яндекс заработают сразу).
4. Запустите рядом ваш zapret (Flowseal winws.exe).

------------------------------------------------------------------------------
 2. РАБОТА С DISCORD: ЕСЛИ У ДРУГА НЕ РАБОТАЕТ ПРОСТОЙ ZAPRET
------------------------------------------------------------------------------
* ПОЧЕМУ ПРОСТОЙ ZAPRET НЕ РАБОТАЕТ НА DISCORD:
  1. ТСПУ блокирует старые пресеты zapret (fake, split2) и детектирует фейковые пакеты.
  2. РКН заблокировал целые подсети Cloudflare IP, на которых работают серверы Discord.
     Обычный zapret не перебирает альтернативные IP, и соединение виснет по таймауту.

* КАК ЭТО РЕШАЕТ FLOWERY:
  По умолчанию в Flowery включен режим: proxy_discord = true (в config.ini).
  Это значит, что Flowery САМ полностью обходит блокировку Discord:
  - Техника "TLS Record Fragmentation": делит рукопожатие на 2 валидные TLS-записи
    прямо по середине имени домена SNI. DPI ТСПУ не видит домены Discord!
  - Протокол Happy Eyeballs (RFC 8305): Flowery параллельно опрашивает все IP 
    серверов Discord за 250 мс и мгновенно подключается к РАБОЧЕМУ незаблокированному IP.
  - Fallback DNS: чистые IP резолвятся в обход подмены оператора.
  В результате Discord (чаты, голосовые каналы, стримы, звонки) работает ДАЖЕ ЕСЛИ 
  простой zapret у друга не работает вовсе!

* ЕСЛИ ВЫ ХОТИТЕ ОТДАТЬ DISCORD ОБРАТНО В ZAPRET:
  Если у вас установлен обновленный Flowseal zapret со специальным пресетом под Discord,
  вы можете открыть "config.ini" и поставить:
  proxy_discord = false
  Тогда Flowery исключит Discord из системного прокси и передаст его в zapret.

------------------------------------------------------------------------------
 3. ТЕСТИРОВАНИЕ РАБОТОСПОСОБНОСТИ
------------------------------------------------------------------------------
* Дважды кликните по "test.bat".
* Скрипт проверит доступность всех ключевых узлов:
  - Discord Web, Gateway, CDN, Voice Media, RTC, Status
  - YouTube, Twitter / X, Rutracker, Cloudflare DNS.

------------------------------------------------------------------------------
 4. ОСТАНОВКА И СБРОС НАСТРОЕК
------------------------------------------------------------------------------
* В окне Flowery нажмите сочетание клавиш [Ctrl + C] — программа автоматически 
  вернет оригинальный системный прокси и настройки реестра.
* Если окно было закрыто принудительно (крестиком), просто запустите "stop.bat"
  для мгновенного сброса настроек прокси в Windows.

------------------------------------------------------------------------------
 5. ФАЙЛЫ В ЭТОЙ ПАПКЕ
------------------------------------------------------------------------------
- start.bat          — Главный лаунчер запуска полного комплекса.
- test.bat           — Экспресс-проверка доступности ресурсов.
- stop.bat           — Экстренный сброс системного прокси и очистка.
- config.ini         — Файл тонких настроек (задержки, техники, TTL).
- whitelist.txt      — Список доменов для обхода.
- Floweryguard/      — Ядро приложения на Python.
- ИНСТРУКЦИЯ.txt     — Этот файл с описанием.
