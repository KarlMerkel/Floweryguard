FLOWERY (GLUE) — версия 1.3.0 в разработке

1. Распакуйте комплект в отдельную доступную для записи папку.
2. Запустите start.bat и разрешите повышение прав.
3. В меню выберите профиль (пункт 2) и включите службу (пункт 1).
   Если служба уже активна, повторное нажатие пункта 1 остановит её.
4. Для завершения выберите 0. Для принудительной остановки есть stop.bat.

Если в комплекте есть исходники, требуется Python 3.8+.
Пакеты pip не нужны. При отсутствии исходников start.bat использует Flowery.exe.
Исходники имеют приоритет над EXE.

Прокси: HTTP/HTTPS CONNECT, адрес 127.0.0.1, порт 8118.
Приложение должно использовать системный прокси Windows или быть настроено вручную.
Это не VPN: внешний IP не меняется. Доступность зависит от сети и оператора.

Права администратора нужны для TTL, MTU, DNS, брандмауэра и WinDivert.
TCP-обход реализован в Python; для голосового UDP Discord используется winws.exe.
stop.bat сбрасывает настройки, включая DNS к DHCP. Ручные настройки могут потребовать восстановления.

Основные пункты меню:
12 — выбор DoH; 13 — калибровка; 14 — диагностика; 15 — тест сайтов;
16 — лог сессии; 17 — обновление доменов; 18 — отправка отчёта после подтверждения.

Логи: папка Flowery\logs внутри системной папки «Документы» (возможен OneDrive).
При проблеме укажите профиль, подключение, сервис и время сбоя.

Подробные команды и настройки описаны в README.md.
