# Инструкция: Бесплатный сервер-шлюз для приёма логов (Cloudflare Worker)

Этот шлюз принимает логи от пользователей Flowery и безопасно пересылает их вам в Telegram.
**Токен бота хранится только на сервере Cloudflare, пользователи его не увидят!**

---

## Быстрый запуск за 2 минуты:

### Шаг 1. Создать воркер
1. Откройте бесплатную панель [dash.cloudflare.com](https://dash.cloudflare.com/) и войдите/зарегистрируйтесь.
2. В левом меню выберите **Workers & Pages** → нажмите синюю кнопку **Create Application** → **Create Worker**.
3. Назовите воркер (например, `flowery-reports`) и нажмите **Deploy**.

### Шаг 2. Вставить код шлюза
1. На странице созданного воркера нажмите кнопку **Edit code**.
2. Удалите стандартный код и вставьте содержимое файла `relay/worker.js`.
3. Нажмите в правом верхнем углу **Save and deploy**.

### Шаг 3. Добавить секретные переменные (Токен и Chat ID)
1. Вернитесь на страницу воркера → перейдите во вкладку **Settings** → раздел **Variables and Secrets**.
2. Нажмите **Add**:
   - Имя переменной: `TELEGRAM_BOT_TOKEN`
   - Значение: токен вашего бота от `@BotFather` (формат `123456789:AA...`)
   - Нажмите галочку **Encrypt** (зашифровать) → **Save and deploy**.
3. Нажмите **Add** ещё раз:
   - Имя переменной: `TELEGRAM_CHAT_ID`
   - Значение: ваш числовой ID в Telegram (можно узнать у бота `@userinfobot` или перейдя по адресу `https://ваш-воркер.workers.dev/my-chat-id` после того, как напишете боту `/start`).
   - Нажмите **Save and deploy**.

### Шаг 4. Указать адрес в config.ini
1. Скопируйте адрес вашего воркера (он отображается вверху страницы воркера, например: `https://flowery-reports.your-subdomain.workers.dev`).
2. В файле `config.ini` укажите:
   ```ini
   [support]
   report_transport = gateway
   report_gateway_url = https://flowery-reports.your-subdomain.workers.dev/report
   ```

Готово! Теперь при нажатии кнопки `18` в меню лог отправляется на ваш шлюз, а шлюз моментально доставляет его вам в Telegram, не раскрывая токен пользователям.
