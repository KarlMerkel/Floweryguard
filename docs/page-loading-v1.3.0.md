# Неполная загрузка страниц, 27 октября 2026

Проверены все шесть скриншотов и публичные запросы к указанным сайтам. В стандартной папке журналов не найден содержательный лог сессии во время скриншотов; путь запущенного процесса недоступен. Поэтому версия работающего на порту 8118 экземпляра не установлена. Ошибка дополнительно воспроизведена на текущих исходниках в изолированной временной копии.

## Что воспроизведено

- `tvrain.tv`: HTML обрывается после 12 537 байт; основной CSS — после 10 107 из 127 998 байт, `polyfills.js` — после 15 037 из 226 314. Меньшие ресурсы загружаются. Это объясняет неоформленную страницу.
- `www.rbc.ua`: HTTP 200, затем неполный HTML, 17 127 байт.
- `soundcloud.com`: HTTP 200, получено 13 855 из 74 409 байт. Несколько CSS/JS тоже обрываются.
- `www.canva.com`: HTTP 403, тело ответа обрывается на 12 967 из 754 650 байт. На скриншоте открыт `/restricted-access/`; устранение обрыва само по себе не гарантирует доступ к сервису.
- `www.last.fm`: одинаковый полный HTTP 403 с телом 425 байт напрямую и через прокси; причина серверного отказа не установлена.
- Patreon на скриншоте явно сообщает запрет доступа из RU (`Error 1009`). Текущий запрос через прокси также получил полный HTTP 403. DPI-обход не меняет внешний IP.

## Подтверждённая ошибка и исправление

CSS `a-v2.sndcdn.com/assets/css/app-3c7028cb7e0129e2a78f.css` на одном и том же адресе `143.204.238.14` полностью загружается напрямую, с `tcp_split_sni_mid` и с `tls_record_frag`: 123 726 байт. С `combo_tlsrec_tcpsplit` он зависает после 15 678 байт. Проверка выполнена с проверкой сертификата, вне транспортного кода прокси.

После такого зависания Flowery менял адрес, но снова выбирал `combo`. Теперь наблюдения о зависшей технике хранятся отдельно для сети, хоста и порта на 45 секунд. На новом соединении выбирается разрешённая альтернатива. Техника, передавшая не менее 64 КБ, временно получает приоритет на 300 секунд. Общие оценки не штрафуются за это подозрение; ручной выбор и отключённые техники сохраняют приоритет. Механизм действует и на повторных попытках TLS.

В живой проверке исправленных исходников первые запросы по-прежнему зависли; следующие получили полный CSS (123 726 байт за 0,16 с) и `dwt.soundcloud.com/tags.js` (139 132 байта за 0,33 с). Смена техники подтверждена журналом. **Основной HTML SoundCloud и CSS «Дождя» альтернативами не восстановлены.** РБК после исправления отдельно не перепроверялся. Полная отрисовка браузера и все зависимости страниц не проверены.

На первоначальном этапе прошли 523 автономных теста. Добавлены проверки реальной отправки выбранной техники, срока действия и области наблюдений, сохранения ручного выбора и отсутствия влияния коротких ответов/WebSocket на временные исключения.

## Повторная проверка адаптивного выбора

Устранена регрессия предыдущего этапа: временные наблюдения о зависании теперь разделены по сети, хосту, порту **и IP**. Сбой техники на одном IP больше не исключает её на другом. Убраны доменные запреты альтернатив в селекторе, принудительный `combo` после смены IP и перезапись накопленных оценок CDN стартовыми предпочтениями. Игры и Telegram начинают с прямой передачи без наблюдений, но TLS-соединения этих сервисов также могут сменить технику. Ручная стратегия сохраняется во всех попытках, включая YouTube. Ограничение обхода списком доменов и настройки разрешённых техник действуют по-прежнему.

Долговременные оценки по-прежнему агрегируются по сети, домену и подсети `/24`. Начальные предпочтения задают порядок проб, но успешные альтернативы могут их вытеснить.

**533 автономных теста прошли.** Локальный EXE пересобран; проверка справки, статуса и внешнего `config.ini` прошла без изменения прокси, TTL и DNS Windows. Сетевые проверки выполнены на текущих исходниках через отдельный прокси, по три запроса каждого ресурса:

| Ресурс | Результат |
|---|---|
| HTML BBC | Три полных HTTP 200 по 661 014 байт |
| Публичная аватарка Discord | Три полных HTTP 200 по 1 268 байт |
| Charter97 | Три полных HTTP 403 по 5 329 байт; доступ не подтверждён |
| Surfshark | Два неполных ответа, затем ошибка TLS |
| CSS SoundCloud | Все три ответа обрываются на 16 384 из 123 726 байт |
| HTML SoundCloud | Все три ответа неполные |

При смене IP стартовая техника может повторяться на неизвестных адресах. Большой пул адресов задерживает проверку альтернативы на том же IP. Полная загрузка Surfshark и SoundCloud не восстановлена; прежний успешный результат отдельных CSS не повторился. РБК, «Дождь», Canva и полная отрисовка в браузере в этом этапе не проверялись. Данные: `scratch/adaptive-strategy-final.json` и `scratch/adaptive-strategy-final-runtime.log`. Ничего не опубликовано.

Диагностические данные находятся локально в `scratch/page-assets/`, `scratch/page-strategies.json`, `scratch/assets-isolated.json` и `scratch/assets-isolated-runtime.log`. Запросы со строкой параметров из первого диагностического прогона не использованы в выводах: там обнаружена ошибка диагностического скрипта, затем исправленная. Пользовательские настройки Windows не изменялись; запущенный экземпляр Flowery не перезапускался. Первый изолированный прогон завершился ошибкой удаления открытого файла журнала после сохранения результатов; в повторном прогоне журнал закрыт и временная папка удалена штатно.
