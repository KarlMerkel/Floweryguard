# Проверка сетевых исключений v1.3.0

Проверены правила выбора адресов и стратегий, классификация доменов, DNS fallback, HTTP-подмены и неработающие переключатели основного Python-пакета. Неверные условия закреплены регрессионными тестами до исправлений.

## Устранено

- Удалены безусловные запреты публичных `192.144.59.14`, `94.232.43.149` и заполнение кэша отказов адресами `204.8.99.144/146` при импорте. Программа не должна делать вывод о текущей доступности адреса по старому списку.
- Удалён скрытый отказ для `dc-telemetry.net` в установлении соединения и резервном DNS. Домен проходит обычную обработку.
- Удалено вытеснение успешно передававших данные адресов из кэша только из-за отсутствия в зашитом пуле Discord/Google.
- Убраны фиксированный «главный» узел Discord, «золотые» адреса, исключение части `162.159.134/135.*` и ротация только из-за недавнего использования. Резервный пул дополняет DNS-кандидатов; наблюдения о передаче имеют приоритет.
- Классификация сервисов теперь проверяет границы доменного имени. `youtube.com.example`, `notgooglevideo.com`, `images-ext.example`, `telegram.example` и аналогичные посторонние имена не получают чужие маршруты. Ответ NCSI не подменяет страницы с похожим именем хоста.
- Автоматический HTTP 301 по умолчанию отключён. Он доступен для GET/HEAD через `[bypass] force_https = true`; POST с телом не заменяется перенаправлением.
- `set_use_hosts_file` больше не пустая функция, а загрузчик `hosts.txt` не вызывает отсутствующую реализацию. При `[targets] use_hosts_file = true` используются явные пользовательские записи рядом с выбранным конфигом. До включения файл не влияет на соединения. Приоритет ручной записи проверен относительно накопленного кэша.
- Пустой ввод своего DNS больше не выбирает автоматически `192.144.59.14`. Без ранее выбранного сервера это возврат без изменений.
- Убраны утверждения, что пауза между `send()` гарантирует физические границы TCP-пакетов.

## Обоснованные ограничения

Loopback, multicast, link-local, RFC 1918, CGNAT, Fake-IP/RFC 2544, зарезервированные IPv4 и IPv6 ULA остаются служебными адресами. Добавлены проверки IPv6 и IPv4-mapped IPv6, чтобы запись в `hosts.txt` не обходила эту политику. Отключённый IPv6 соблюдается и для ручных адресов.

Сохраняются настраиваемые NCSI/HTTP-функции, явные пользовательские стратегии, начальные оценки, адреса DNS-провайдеров и резервные CDN-кандидаты. Это настройки и подсказки, а не утверждения, что публичный адрес навсегда рабочий или нерабочий. Исходная проверка TLS-сертификатов не отключалась.

## Проверка

- **555 автономных тестов прошли** через `tests/run.py` во временной копии проекта. Ключевые контракты: `test_route_policy_contract.py`, `test_explicit_routing_options.py`; прежние тесты с требованиями постоянных запретов/принудительной ротации обновлены под наблюдаемое поведение.
- В сетевом прогоне полностью получены YouTube, Meduza, Signal, публичная аватарка Discord и Localize. HTML Discord сначала обрывался на двух адресах; в отдельном повторе полностью получен три раза через другой адрес из DNS. Это подтверждает зависимость от маршрута, а не постоянную исправность всего пула.
- Системные настройки и пользовательские оценки не использовались как тестовые данные для записи. Исходники локальной релизной копии синхронизированы.
- EXE пересобран. `smoke_frozen.py --network` подтвердил справку, внешний конфиг, запуск/остановку отдельного прокси, закрытие порта и неизменность системных настроек. В этом прогоне Discord Web/Status, X и RuTracker дали таймаут, YouTube ответил; HTTP-ошибки тестовых адресов и отсутствие ответа UDP не считаются доказательством доступности сервисов или конкретной причины блокировки.

В локальный `AGENTS.md` добавлены правила против возврата необоснованных запретов и неработающих переключателей. Этот файл исключён существующим `.gitignore`; регрессионные тесты и данный отчёт сохранены в Git.

Проверка не означает устранение всех сетевых проблем: выбор среди неизвестных адресов по-прежнему может сначала дать неудачный маршрут. Ранее отмеченные HTTP 403 и неполные загрузки отдельных сайтов не объявляются исправленными. Публикации нет.
