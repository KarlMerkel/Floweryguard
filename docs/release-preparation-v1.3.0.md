# Подготовка локального выпуска 1.3.0

Дата: 27 октября 2026 года. Публикация не выполнялась, тег выпуска не создан.
Исходная ревизия архивов: `b0df18c498d1a8ea5c54ef9b3940b5bad06c414b`.

Комплекты находятся в `dist/release-candidate/b0df18c498d1/`:

- `Flowery-v1.3.0-windows-x64.zip` — автономный EXE, чистые настройки, инструкции и лицензии.
- `Flowery-v1.3.0-source.zip` — исходники, тесты, сборочные скрипты и используемые бинарные компоненты.
- `SHA256SUMS.txt` и `release_manifest.json` — суммы архивов и привязка к ревизии.
- `RELEASE_NOTES.md` — текст описания релиза с отличиями от 1.2.0.

Архивы исключают журналы, пользовательские оценки стратегий и привязки сетей. Встроенный `hosts.txt` берётся из чистого шаблона. `BUILD_INFO.json` связывает EXE с хэшами исходников и ресурсов; упаковка отказывается принимать изменившиеся входные файлы. Контрольные суммы обеспечивают проверку целостности, но не являются цифровой подписью издателя.

Проверки: 564 автономных теста, повторно 564 теста из распакованного архива исходников, 2 теста шлюза. Для обоих ZIP проверены все записи по манифестам. Проверка текстовых файлов исходного комплекта по шаблонам токенов Telegram и закрытых ключей совпадений не обнаружила; это не исчерпывающий аудит секретов.

Новый EXE прошёл `tests/smoke_frozen.py --network`: справка, внешний конфиг, статус, запуск и остановка временного прокси, закрытие порта. Значения системного прокси, DNS и TTL до и после совпали. Полная сессия с применением настроек под правами администратора этим тестом не проверяется.

Встроенная сетевая диагностика: YouTube и Discord Status ответили; Discord Web, X и RuTracker дали таймауты. Ответы 403/404/520 на остальных диагностических URL не подтверждают загрузку пользовательских страниц. Проверка UDP без включённого голосового помощника не доказывает работоспособность звонков.

По последнему сообщению пользователя Discord восстановился после 1–2 минут использования. Это наблюдение совместимо с адаптацией маршрутов, но не гарантирует доступность во всех сетях. Оценки техник сохраняются между запусками; краткосрочные наблюдения о маршрутах истекают. Эти различия отражены в описании релиза.

PyInstaller сообщил об отсутствующих при упаковке `fwpkclnt.sys`, `NDIS.SYS`, `WDFLDR.SYS`: это системные зависимости драйвера WinDivert, а не Python-модули. Проверка EXE без запуска драйвера не подтверждает работу UDP-помощника. Тексты сторонних лицензий сохранены с исходным форматированием. Сверка происхождения бинарников и условий распространения, актуальности шлюза логов и отзыва старого токена остаётся перед публичным выпуском.

Прежний рабочий комплект `dist/Flowery-v1.3.0-portable` обновлён после закрытия пользователем Flowery. Его настройки сохранены. Для чистой установки используйте ZIP в каталоге кандидата; перед откатом завершайте новую версию штатно.
